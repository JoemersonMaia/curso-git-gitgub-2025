COMANDOS GIT
git init . -> trasforma pasta em um repositorio
git status -> como esta o repositorio
git add nome_arquvio -> sinaliza o que vai entrar no commit
git commit -m "" -> fazer um commit 
$ git --global user.email"" user.nome"" -> "criar um usuario"
nano comandos.git.txt -> criar arquivo editavel
git log -> ver todos os commits
git dff npme_arquivo -> vizualizar o que vai ser adicionado

BRANCH
git chekout -b nome_chekout -> criar save
git branch -> mostrar as branchs
git chekout nome_da_branch -> se mover pelas branchs
git merge nome_arquivo -> mesclar branchs
git branch -d secundaria -> apagar branch
git push origin main -> subir commit
git pull origin main -> pegar commits do github para repositorio local
